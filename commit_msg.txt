feat: initial release of Student Management System

Core implementation of a role-based school management platform featuring Admin, Teacher, and Student modules.

Key features included:
- **Role-Based Access Control**: Secure login and distinct dashboards for Admins, Teachers, and Students.
- **Student Management**: Full CRUD operations for student records and performance monitoring.
- **Attendance System**: Real-time attendance logging and historical data tracking.
- **Academic Records**: Grade management system with reporting capabilities.
- **Administrative Tools**: Activity logs, teacher management, and report generation.
- **Database Infrastructure**: PostgreSQL integration using PHP PDO and database setup automation.
- **Deployment Ready**: Security enhancements and configuration updates for live environment preparation.
